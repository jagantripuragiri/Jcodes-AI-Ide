# J Code - AI-Powered IDE

<div align="center">
	<h1>J Code's</h1>
</div>

J Code is an AI-powered IDE built on top of the open-source VS Code foundation. It offers a secure, tightly integrated environment featuring native AI code generation, inline autocomplete, agentic tasks, semantic search, and project context understanding.

## Features

- **AI-Powered Workflows:** Integrated AI assistance for code generation, agentic automation, inline edits, and interactive chat.
- **Privacy & Control:** Secure development experience with minimal telemetry and full developer control over model configurations.
- **GitHub Dark Aesthetics:** A sleek, curated developer-focused theme designed for clarity and focus.
- **Seamless Developer Experience:** Built on the robust VS Code open-source base for high compatibility and performance.

## Getting Started

To run J Code locally:
1. Run `npm install`
2. Run `npm run watchreact` in one terminal window.
3. Run `npm run watch` in another.
4. Finally, run `./scripts/code.sh` on macOS/Linux or `.\scripts\code.bat` on Windows.

## Configuration

Configure AI features by navigating to **J Code Settings** in the IDE sidebar to set up your preferred AI model provider and API credentials.
