# J Code's - AI-Powered IDE

<div align="center">
	<h1>J Code's</h1>
	<p>An AI-first coding environment built on the open-source VS Code foundation</p>
</div>

J Code's is an AI-powered IDE created to help developers write, understand, edit, and ship code faster. Built on top of the open-source VS Code codebase, it combines the familiarity and stability of a modern editor with deeply integrated AI workflows tailored for real development work.

## What is J Code's?

J Code's is designed as a practical AI development environment for developers who want more than a basic code editor. It brings together:

- AI-assisted code generation
- Inline autocomplete and editing
- Agentic workflows for multi-step tasks
- Project-aware context understanding
- Semantic code exploration
- A familiar editor experience powered by VS Code

The goal is to make AI feel like a native part of the editor instead of an external add-on.

## Core Features

- **AI-Native Coding Experience:** Generate, edit, refactor, and explain code directly inside the IDE
- **Inline Assistance:** Get fast autocomplete and contextual suggestions while you type
- **Agentic Task Flows:** Let the IDE help with larger multi-step coding workflows
- **Project Context Awareness:** Improve output quality with better understanding of your workspace and codebase
- **Semantic Search & Navigation:** Explore code more intelligently across files and features
- **Built on VS Code:** Keep the reliability, compatibility, and workflow familiarity developers already know
- **Developer-Focused Experience:** Clean interface, productive defaults, and an environment made for serious coding work

## Why J Code's?

J Code's is intended for developers who want:

- A code editor with deeply integrated AI
- A productive local development workflow
- Familiar VS Code foundations with custom AI capabilities
- Better support for understanding and modifying large codebases

## Getting Started

To run J Code's locally:

1. Run `npm install`
2. Run `npm run watchreact` in one terminal
3. Run `npm run watch` in another terminal
4. Launch the app with `./scripts/code.sh` on macOS/Linux or `./scripts/code.bat` on Windows

## Configuration

Configure the AI features inside the product settings and related J Code's panels, where you can set up supported providers, models, and credentials based on your workflow.

## Project Foundation

This project is a custom IDE experience built from the open-source VS Code repository and extended with J Code's-specific AI features and workflows.
